Portable environment and cache execution

Commands are passed through a quoted shell argument, including nested Python -c programs and complete pipelines. Docker retains its GNU timeout; local execution uses a deadline on the run's private process group and retains the caller's PATH. The Qlib Docker configuration opts into the existing MLflow file store with MLFLOW_ALLOW_FILE_STORE=true. User-supplied local volume paths are temporarily preserved beside the mount and restored after removing only the created symlink.

Workspace hashes exclude .venv, venv, .git, and __pycache__. ZIP creation prunes those directories and the configured cache root, and never includes its own output archive. Full-restore caches stored inside their own input directory execute uncached: restoring such a cache would clear the directory containing the cache. This avoids recursive archive growth and preserves repository and user files. The generated 547,968,106,600-byte self-archive and its 245-byte marker were removed by exact path after verification; all other caches and user files were preserved.

API tests need valid chat/embedding credentials and a reachable endpoint. Context7 and Kaggle cases need their actual service credentials and endpoints. The standalone connectivity script no longer overwrites application credentials during pytest collection; its existing test_model(model) still reports a missing fixture in the full suite and is retained as a blocker. No network test was skipped or replaced.

Current Pydantic-AI uses MCPToolset. Synchronous agent calls preserve the standard asyncio runtime; a caller already inside a notebook event loop uses a private worker thread.
